# 🪢 TugSnap

**Auto play for Ink Game minigames on Roblox.** TugSnap pulls in **tug of war** and wins the **Mingle** Power Hold key checks for you.

> [!IMPORTANT]
> **Requires AutoHotkey v2** (free). It will **not** run on AutoHotkey v1.1. [Get AutoHotkey v2 here.](https://www.autohotkey.com/)

- 🪢 **Tug of war:** hits the red zone dead center. It tracks the dot's speed and direction and times each press ahead of time, even when the dot speeds up.
- 🤼 **Mingle:** reads the key on each Power Hold button (R, G, F, Q or E) and presses it as the shrinking circle reaches the red ring. Handles several buttons at once, anywhere on screen.
- ✅ **Pick your games.** Turn tug of war and Mingle on or off with a checkbox each.
- 🧠 **Timing tunes itself.** After every tug it checks where the dot bounced back and corrects for your PC's input lag. No sliders to fiddle with.
- 📊 **Mini stats HUD.** A click-through overlay with tugs, rounds, tugs/min, dot speed, Mingle keys, timing and run time.
- 🌙 **Dark mode** and a small settings menu. Your settings are saved.
- 🔔 **Update notifications** when a new version is out.
- 🛡️ **Only presses keys while Roblox is focused**, so it never types into other windows.

## Download
### ⬇️ [Download the latest release](https://github.com/brageat/tugsnap/releases/latest)

1. Install **[AutoHotkey v2](https://www.autohotkey.com/)**, the free, official program that runs the script. On the AutoHotkey site, click **Download v2.0**, not v1.1.
2. Download **`TugSnap.ahk`** from the release.
3. Double-click it.

> No exe to trust: `TugSnap.ahk` is a plain text file, so you can open it in Notepad and read exactly what it does.

## Use
1. Run Roblox **fullscreen** (normal or borderless).
2. Press **F6** (or click **Start**). The HUD shows **● TUGSNAP ON**.
3. Play. TugSnap pulls in tug of war and presses the Power Hold keys in Mingle. The first few tugs fine-tune the timing.

## Disclaimer
Using macros may break Roblox's or the game's rules. Use at your own risk.
