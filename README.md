# 🪢 TugSnap

**Auto tug for Ink Game's tug of war on Roblox.** TugSnap watches the tug ring and presses Space the moment the green dot lines up with the red zone.

> [!IMPORTANT]
> **Requires AutoHotkey v2** (free). It will **not** run on AutoHotkey v1.1. [Get AutoHotkey v2 here.](https://www.autohotkey.com/)

- 🎯 **Hits the red zone dead center.** It tracks the dot's speed and direction and times each press ahead of time, even when the dot speeds up.
- 🧠 **Timing tunes itself.** After every tug it checks where the dot bounced back and corrects for your PC's input lag. No sliders to fiddle with.
- 📊 **Mini stats HUD.** A click-through overlay with tugs, rounds, tugs/min, dot speed, timing and run time.
- 🌙 **Dark mode** and a small settings menu. Your settings are saved.
- 🛡️ **Only presses Space while Roblox is focused**, so it never types into other windows.

## Download
### ⬇️ [Download the latest release](https://github.com/brageat/tugsnap/releases/latest)

1. Install **[AutoHotkey v2](https://www.autohotkey.com/)**, the free, official program that runs the script. On the AutoHotkey site, click **Download v2.0**, not v1.1.
2. Download **`TugSnap.ahk`** from the release.
3. Double-click it.

> No exe to trust: `TugSnap.ahk` is a plain text file, so you can open it in Notepad and read exactly what it does.

## Use
1. Run Roblox **fullscreen** (normal or borderless).
2. Press **F6** (or click **Start**). The HUD shows **● TUGSNAP ON**.
3. Join tug of war and let TugSnap pull. The first few tugs fine-tune the timing.

## Disclaimer
Using macros may break Roblox's or the game's rules. Use at your own risk.
